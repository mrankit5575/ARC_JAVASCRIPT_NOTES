# JavaScript & React 

This repository contains learning resources and example code from my **JavaScript and React JSX teaching playlist**.  
The playlist is designed to help students understand **JavaScript fundamentals deeply and move toward modern React development**.

This course focuses on **concept clarity, practical examples, and real-world development practices**, making it ideal for beginners as well as developers who want to strengthen their core JavaScript knowledge before learning advanced frameworks.

---

## 📚 What You Will Learn

This playlist covers JavaScript from **basic to advanced concepts** and then introduces **React JSX development**.

### JavaScript Fundamentals
- Introduction to JavaScript
- Variables (`var`, `let`, `const`)
- Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Objects

### Intermediate JavaScript
- DOM Manipulation
- Events
- ES6+ Features
- Arrow Functions
- Destructuring
- Spread & Rest Operators
- Template Literals
- Modules

### Advanced JavaScript
- Closures
- Scope & Hoisting
- Promises
- Async / Await
- Fetch API
- Error Handling
- JavaScript Execution Context
- Event Loop
- Callback Queue

### React JSX Concepts
- Introduction to React
- JSX Syntax
- Components
- Props
- State
- Conditional Rendering
- Lists & Keys
- Event Handling in React
- React Folder Structure

### React Router
- Introduction to Routing
- React Router DOM
- Dynamic Routing
- URL Parameters
- Navigation with Link
- Route Configuration

### Real Development Concepts
- API Integration
- Dynamic UI Rendering
- Component Reusability
- Folder Structure for Projects
- Best Practices for Clean Code
